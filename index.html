    What you will learn¶

    • Understand OS structure and function

      What an operating system does, how it evolved, and the architectural choices (monolithic, microkernel, modular) that shape its behaviour.

    • Manage processes and threads

      Process concepts, context switching, thread models, CPU scheduling algorithms (FCFS, SJF, Round Robin, priority, multilevel feedback), and real-time scheduling.

    • Coordinate concurrent processes

      Race conditions, critical sections, Peterson's solution, semaphores, monitors, and classical synchronisation problems (producer–consumer, readers–writers, dining philosophers).

    • Handle deadlocks

      Deadlock characterisation, prevention, avoidance (Banker's algorithm), detection and recovery.

    • Manage memory

      Partitioning, paging, segmentation, virtual memory, page-replacement algorithms (FIFO, LRU, Optimal), and thrashing.

    • Implement file systems and I/O

      File system structure, allocation methods, directory implementation, I/O software layers, buffering, and disk caching.

    • Reason about OS security

      Threats, attacks, authentication, access control, and common defences.
