# Feedback and Corrections

If you spot an error, a typo, or a broken link, please report it.

---

## What to report

| Category | Examples |
|---|---|
| Typo | Misspelled word, wrong symbol |
| Mathematical error | Wrong formula, missing factor |
| Broken link | 404 on a chapter or reference |
| Rendering problem | Equation not displaying |
| Clarity issue | Ambiguous definition, skipped proof step |

---

## How to report

Open a GitHub issue at `github.com/YOUR-USERNAME/ECEG-5202/issues` with:

- Page path
- Section
- What is wrong
- What it should be
- Severity (typo / minor / major / blocking)

---
